# 60 Days Coding Challenge 🚀

Welcome to my **60 Days Coding Challenge** repository! This project documents my journey in mastering C++, Object-Oriented Programming (OOP), and Data Structures & Algorithms (DSA) over the course of two months.

## 📂 Repository Structure

The repository is organized into four main categories:

- **Basics**: Fundamental concepts of C++ programming.
- **OOP**: Deep dive into Object-Oriented Programming principles.
- **DSA**: Implementation of key Data Structures and Algorithms.
- **Projects**: Mini-projects and games to apply learned concepts.

---

## 📚 Key Topics Covered

### 🔹 Basics
Focus on building a strong foundation in C++ syntax and logic.
- **Control Flow**: Loops (`loop.cpp`, `break.cpp`), Conditional Statements (`nestedIfElse.cpp`, `switch_cal.cpp`).
- **Functions**: User-defined functions, recursion (`Recursion.cpp`, `fun_prime.cpp`).
- **Patterns**: various pattern printing problems (`pattern1.cpp` to `pattern6.cpp`, `dimand.cpp`).
- **Math & Logic**: Number conversions (`Binary_to_Decimal.cpp`), Factorials (`factorial.cpp`), Palindromes (`palindrome.cpp`).
- **Pointers & References**: Understanding memory checks and references (`reference.cpp`).

### 🔹 Object-Oriented Programming (OOP)
 mastering the core pillars of OOP.
- **Classes & Objects**: Basic class definition (`01_class.cpp`, `oops_Person.cpp`).
- **Inheritance**:
  - Single (`Single_inheritance.cpp`)
  - Multi-level (`Multi_level_inheritance.cpp`)
  - Multiple (`Multiple_inheritance.cpp`)
  - Hierarchical (`Hierarchical_inheritance.cpp`)
  - Hybrid (`Hybrid_inheritance.cpp`)
- **Polymorphism**: Compile-time & Run-time (`Compile_time_polymorphism.cpp`, `Run_time_polymorphism.cpp`, `4_FunctionOverloading.cpp`).
- **Encapsulation**: Data hiding and access specifiers (`encapsulation.cpp`, `6_Getter.cpp`).
- **Abstraction**: Abstract classes and interfaces (`Abstraction.cpp`).
- **Advanced Features**: Templates (`7_ClassTemplate.cpp`), Exception Handling (`8_ExceptionHandling.cpp`).

### 🔹 Data Structures & Algorithms (DSA)
Implementing efficient algorithms and data organization.
- **Searching**: Linear Search (`linear_search.cpp`), Binary Search (`binary_search.cpp`), BFS (`Breadth_first_search.cpp`), DFS (`Depth_first_search.cpp`).
- **Sorting**: Bubble Sort (`bubble_sort.cpp`), Insertion Sort (`insertion_sort.cpp`), Selection Sort (`selection_sort.cpp`), Merge Sort (`merge_sort.cpp`), Quick Sort (`Quick_sort.cpp`).
- **Linked Lists**: Singly & Doubly Linked Lists (`singly_linked_list...`, `Doubly_linked_list...`).
- **Trees**: Binary Search Trees (`Binary_search_tree.cpp`).
- **Stacks & Queues**: Implementation and basic operations (`stack_PUSH_and_POP.cpp`, `queue_insert_and_delete.cpp`).
- **Hashing**: Hash techniques (`hashing_techniques.cpp`).

### 🔹 Projects
Fun applications to test skills.
- **Games**: Magic Game (`magicGame.cpp`), Number Guessing (`numberGuessing.cpp`).
- **Simulations**: Donut render (`donut.cpp`).
- **Utilities**: Age Calculator (`age_calculater.cpp` in Basics).
